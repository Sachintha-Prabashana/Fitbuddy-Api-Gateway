## Project Description
The API Gateway acts as a single entry point for all client requests, routing them to the appropriate microservices.

## Technology Stack
- Java 25
- Spring Boot 4.0.1
- Spring Cloud Gateway
- Maven

## Setup / Getting Started Instructions
1. Clone the repository.
2. Navigate to the `api-gateway` directory.
3. Run `./mvnw clean install` to build the project.
4. Start the application using `./mvnw spring-boot:run`.
5. Access the gateway at `http://localhost:8000`.
